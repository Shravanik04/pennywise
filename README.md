# Pennywise — Money, made mindful 💸

Pennywise is a personal finance app for tracking expenses, organizing budgets, and understanding spending patterns. Add expenses manually or scan a receipt. Extracted receipt details can be reviewed and edited before they are saved.

🌐 **Live app:** [https://pennywise-orcin.vercel.app](https://pennywise-orcin.vercel.app)

## ✨ Features

- ✍️ Add and manage expenses manually.
- 🧾 Scan receipt images and PDFs, then review and edit extracted details before saving.
- 🗂️ Categorize items and view category totals.
- 🎯 Set monthly budgets and track spending.
- 🔎 Search expense history and filter by category or date range.
- 📊 View calculated spending insights and ask questions about saved expenses.
- ☁️ Use browser-local storage or, when configured, Supabase authentication and account-scoped cloud data.
- 📅 Filter dashboard totals, category breakdowns, charts, transactions, and budget progress by month, year, or a custom date range.
- ⚙️ Choose a date format, export expenses to CSV, and clear this browser’s Pennywise data from Settings.
- 🆘 Find setup, receipt scanning, account, privacy, and troubleshooting guidance in Help & Support.
- ✉️ Contact support at [pennywiseapp2026@gmail.com](mailto:pennywiseapp2026@gmail.com).

## 💾 Storage modes

### 🖥️ Browser-local mode

Without Supabase configuration, Pennywise runs in local-only mode. Expenses, budgets, receipt files, and app preferences are stored in this browser. They persist after refresh but are not backed up or shared between devices or users.

### 🔐 Supabase mode

When Supabase is configured and connected, Pennywise uses Supabase Auth and stores expenses and budgets in the signed-in user’s account. Row Level Security policies restrict access to each user’s records, and Supabase Realtime updates connected sessions.

Receipt file contents remain on the device where they were uploaded. Existing browser-local expenses and budgets are not automatically copied to Supabase when cloud mode is enabled.

## ⚙️ Configure Supabase

1. Create a Supabase project and enable email/password authentication.
2. Run [`supabase/migrations/20261028000000_create_expenses.sql`](supabase/migrations/20261028000000_create_expenses.sql) in the Supabase SQL Editor.
3. Copy `.env.example` to `.env.local` and add your project URL and public key:

   ```env
   VITE_SUPABASE_URL=https://your-project-id.supabase.co
   VITE_SUPABASE_ANON_KEY=your-publishable-or-anon-key
   ```

4. In Supabase, open **Authentication → URL Configuration**. Set the Site URL to your deployed app, then add your local and deployed app URLs to Redirect URLs:

   ```text
   http://localhost:5173/**
   https://pennywise-orcin.vercel.app/**
   ```

   Use the local port shown by Vite if it differs.

5. Restart the development server and sign up or log in through Pennywise.

Never put a Supabase `service_role` or secret key in frontend code.

## 🧾 Receipts and insights

Receipt images are processed in the browser using Tesseract.js. PDF pages are rendered in the browser with PDF.js before OCR. An internet connection is needed for the first scan to download OCR language data.

OCR results are suggestions. Review and edit the merchant, date, totals, tax, items, and categories before confirming an expense.

Dashboard totals, category allocations, spending patterns, and Ask Penny answers are calculated from saved expenses. They are not generated by a connected AI service and are not financial advice.

## 🗓️ Dashboard date filters

Use the Dashboard date menu to choose this month, the previous month, a specific month and year, a year, or a custom date range. Both dates in a custom range are included. The selected period updates the dashboard’s totals and visualizations.
